# Surface brief: UGC Factory control floor (`ugc-system/ui/`)

Scope: single-page operator console (web, desktop-first) over the Python UGC engines. Mode: Operate. Audience: Kartik, solo operator running AI influencer accounts daily.

## Direction contract

THESIS: The content pipeline is a physical production line — the operator watches one idea travel INTAKE → ANALYZER → STYLIST → EXPRESSION → DISPATCH on a steel conveyor rail. It refuses the generic AI-dashboard grid of floating rounded cards.

OWN-WORLD: Matte steel blue-grey machine enamel panels with bolt heads and seams; hazard-yellow floor-tape grid as the always-visible construction armature; safety signal language — amber = in-transit, machine green = genuine/passed, signal red = performed/REMIX stamp; stencil station numerals; dot-matrix LED counters; monospace data labels; knurled metal dials for MDEP; cream paper job tickets for briefs. Dark ground is earned: night-shift control floor under task lamps.

STORY: The operator pastes a reel + context, the token advances station by station, each station shows its machine reading (hook type, beat ladder, formality meters, genuine/performed lamp), and a paper job ticket prints at DISPATCH with hook, script, style, expressions, caption.

FIRST VIEWPORT: Full-width riveted header with LED band (BRIEFS/QUEUE/TAKT + persona chip) on top; the conveyor rail crossing the screen horizontally at mid-height with five station panels mounted on it and an amber token between stations; 01 INTAKE largest and leftmost holding a 9:16 reel viewport + transcript/context/idea inputs; dial bank (MOOD/DAY/ENVIRONMENT/PLACE) along the bottom edge with a live mono readout strip.

FORM: Conveyor-spine topology (comp 1 direction) fused with the console's oversized ANALYZER beat ladder and the dispatch wall's ticket columns collapsed into the single-line flow; the feed's 9:16 viewport lives inside INTAKE. Signature interaction: the amber job token travels the rail as the operator advances the line; MDEP dials re-map style/expression readouts live with a mono state readout. Ranked structure choice: conveyor spine was the top-ranked grounded candidate.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Unresolved: none blocking. LED/takt numbers are synthetic demo data (labeled as such in code comments); real counts come from `data/briefs/` later.
